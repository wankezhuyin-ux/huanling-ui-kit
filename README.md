# 幻灵归虚 · UI 套件仓库

游戏 UI 的可复用素材 + 装配验证台 + 生成管线。**像素全部取自三张概念图原图，没有一处重绘。**

这套是给《幻灵归虚 / 水墨灵兽》客户端用的：把概念图里的 UI 拆成带 alpha 的 PNG，
配好九宫格切边，能直接进引擎。当前基准 **1x**（900 宽设计稿）。

---

## 一、先看什么

```bash
open 09_实装测试/index.html    # 三页真实装配效果（可交互，带滑杆调拉伸）
open 08_预览/preview.html      # 每件素材单独长什么样
```

- `09_实装测试/index.html?play=1` → 进"游戏模式"：铺满窗口，底部导航可点着切页
- `09_实装测试/实装测试报告.md` → 装进界面后暴露的 10 处问题怎么修的 + 7 项遗留局限
- `索引.md` → 素材清单：尺寸 / 九宫格切边 / 用途
- `00_说明/SPEC.md` → 方法论：形状怎么判、字怎么擦、边怎么修

## 三、三条铁律（改之前必读）

1. **不许重绘、不许"优化"形制。** 笔锋、双层描边、菱形回纹都在原位，是像素级搬运。
   试过用生图模型重画整套 —— 形制走形、金边变细断线，已否决并回退。
2. **图里不能有字。** 文字装配时另起一层，字号/字色在 `09_实装测试/index.html` 里。
3. **严格 1:1。** 不要随手放大某个件，会破坏件与件的对齐。

## 四、接引擎时

```
面板类：frame（边框环）+ fill（paper_fill 平铺）两层，不能只贴一层
名条/页签/按钮：9-slice，切边见 九宫格切边.json，纵向不切片
圆形件：只等比缩放，不要拉伸
```

**唯一不能自由拉伸的是 `04_按钮/btn_gold.png`**：左端装饰占 101/305，
压到 250 宽会出接缝。按原生 305 用，或整体等比缩放。

## 五、重跑生成管线

```bash
cd 10_生成脚本 && pip install -r requirements.txt && cd build
python3 final9.py       # 全部几何件 → ../out/v9/
python3 fix_plates.py   # 名条专项重修
python3 make_paper.py   # paper_fill.png
python3 round.py        # 圆形件 alpha
python3 sync9.py        # 同步到仓库根 + 重算索引与切边
```

## 六、已知局限

1. 源图只有 **1x**，上 2x/3x 设备会软 —— 分辨率决定，不是处理问题。
2. 名条有一端笔锋是**镜像补**的（原图被立绘压住），放大能看出。
3. 宠物立绘原图仅 180px 高，需要原画资源替换。
