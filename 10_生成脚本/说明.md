# 10_生成脚本 · 说明

这套脚本负责**把概念图拆成素材**。不要手改 PNG——改参数、重跑。

## 结构

```
10_生成脚本/
├── src/            A_battle.jpg  B_pet.jpg  C_city.jpg   ← 唯一真源
├── out/v9/         生成的中间产物（跑完才有）
├── build/          脚本本体
└── requirements.txt
```

## 运行顺序（必须按这个顺序）

```bash
pip install -r requirements.txt
cd build

python3 final9.py       # 全部几何件 → out/v9/，同时写 out/v9/pos.json（落点表）
python3 fix_plates.py   # 名条重修（依赖 final9 的产物）
python3 make_paper.py   # paper_fill.png
python3 round.py        # 圆形件 alpha（直接写交付目录 07_写实件/）
python3 sync9.py        # 同步到交付目录，重算 索引.md / 九宫格切边.json
python3 compare9.py     # 出「原图 vs 抠件」对照图，肉眼验一遍
```

## 各脚本干什么

| 脚本 | 作用 |
|---|---|
| `final9.py` | 主生成器。`plate_mask()` 判形状、`pick()` 取最大连通域、`strip()` 擦字、`corner_clean()` 清角、`round_corners()` 收圆角、`mirror_cap()` 补端头。JOBS 表定义 22 件各自的裁切框与处理参数 |
| `fix_plates.py` | 名条专项。`plate_mask` 换成更紧的色相+明度组合，补端头改成「只取未遮挡侧的干净笔锋，带 alpha 叠到缺的那端」，不拼接延长 |
| `make_paper.py` | 从日志面板内部取干净纸面，按行中值去残迹，做可平铺的 `paper_fill.png` |
| `round.py` | 方形底的圆形件按圆盘半径重做 alpha（`r = 边长 × 0.44~0.46`），1px 抗锯齿 |
| `sync9.py` | 把 `out/v9` 同步进交付目录，并按实际尺寸重写索引与九宫格 JSON（切边自动夹到 ≤45%） |
| `compare9.py` | 生成对照图 |
| `pix.py` / `seg.py` / `kit.py` | 公共库：形状工具、分割、像素操作 |

## 改参数时的三条注意事项

1. **不要加"边缘去污染"**。看起来能消背景晕边，实际会把 2~3px 的金色描边替换成底色，
   整套件的金边就是这样被毁过一次。
2. **擦字不要刷死底色**。用 `cv2.inpaint(TELEA)`，保持纸纹/笔触连续；金饰要开色相保护。
3. **竖排窄牌不要用行中值判字**，会取到字色本身。改用白字掩膜 + inpaint。

## 新增一件素材怎么做

在 `final9.py` 的 `JOBS` 表里加一行：`(输出名, 源图 key, 裁切框, 是否擦字, 擦字框, 附加参数)`，
跑一遍 `final9.py`，再到 `sync9.py` 的清单里登记 `(文件名, 子目录, 中文名, l, r, t, b, 用途)`，
跑 `sync9.py` 就会自动进交付目录、进索引、进切边 JSON。
